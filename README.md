# Mon Portfolio - Adama Traoré

Portfolio web personnel présentant mes compétences, expériences professionnelles et réalisations en génie logiciel et développement d'applications full-stack (Web, Mobile & APIs).

## 🛠️ Stack Technique

- **Backend** : Laravel 12 (PHP 8.2+)
- **Frontend & UI** : Blade Templates, TailwindCSS v4, Vite
- **Conteneurisation** : Docker, Docker Compose
- **Qualité & Tests** : PHPUnit, Laravel Pint

## 📂 Structure & Sections

- **À Propos (`about`)** : Parcours académique (Licence Génie Logiciel - UVBF), vision d'ingénierie et compétences transversales.
- **Expérience (`experience`)** : 
  - **Safrimat Burkina (CDD)** : Conception et développement d'applications métier internes pour les équipes commerciales, projets Safrimat Immo, Fruits & Légumes (Laravel, Flutter, Supabase, Firebase).
  - **ETP4A** : Mentorat technique et formation en développement full-stack.
- **Réalisations (`projects`)** : Showcase des solutions web, mobiles (dont APK List, Safrimat Immo), IA & multimédia (Auto-Recap), Java EE et back-offices en production ou privés avec filtrage dynamique et pagination réactive.
- **Compétences & Certifications** : Core stack (Laravel, Flutter, Node.js, PostgreSQL, FastAPI, Docker), architecture logicielle, sécurité applicative (OWASP) et DevOps.
- **Contact** : Formulaire et canaux professionnels directs.

## 🚀 Installation & Lancement

```bash
# Cloner le dépôt et installer les dépendances
composer install
npm install

# Configuration de l'environnement
cp .env.example .env
php artisan key:generate

# Démarrer en local
npm run dev
php artisan serve
```
